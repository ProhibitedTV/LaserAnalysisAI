# LaserLab v0.9.7 — CodeOfReality research integration

This release adds the seven CodeOfReality reference fonts supplied by the
project maintainer and the experimental visual-comparison tools built around
them, while retaining LaserLab's blinded, control-based analysis workflow.

## Downloads

The official GitHub release contains native ZIP archives and matching
`.zip.sha256` checksums for:

- Windows x86-64
- Linux x86-64
- macOS Intel x86-64
- macOS Apple Silicon arm64

Each ZIP contains the native desktop dashboard (`LaserLab` or
`LaserLab.exe`), a command-line launcher (`LaserLabCLI`), README, license,
public sample media, `BUILD-INFO.json`, `SHA256SUMS`, the seven verified
CodeOfReality fonts, and the bundled distribution provenance notice.
The release build checks native startup, resources, demo, font registration,
font SHA-256 fingerprints, CLI diagnostics, and a synthetic optical benchmark.
On Linux it also runs an extracted X11 dashboard startup check.

## New in this release

- Seven CodeOfReality font variants in **Appearance > Wordmark font** and
  a guided local installer; each font is checked against the reviewed
  SHA-256 manifest.
- Opt-in experimental glyph-reference OCR for selected ROIs, with multi-scale
  (96/64/40/24 px) templates, conservative abstention, and per-glyph boxes.
  Experimental font matches remain outside the primary Tesseract agreement
  and scientific detector scoring.
- `font-verify --require-all` audits every reference font in the installed
  or packaged build.
- `font-calibrate --variant all` evaluates synthetic same-font glyph
  self-consistency and negative controls, explicitly **not** accuracy on
  recorded laser or DMT-reported imagery.
- `symbol-compare` compares an independently supplied reference image of
  reported symbols with a laser image, and optionally a separate laser
  control, while reporting Tesseract output and shape similarities distinctly.
- Bundled distribution attestation and fail-closed release checks, with
  checksum and embedded Qt font-registration verification.

## Example comparison

```powershell
LaserLabCLI.exe symbol-compare --laser-image "laser.png" --reported-symbol-image "reported-symbol.png" --control-laser-image "control.png" --variant all
```

Run `LaserLabCLI.exe --help` for all options. For Linux/macOS use
`./LaserLabCLI` instead.

These procedures compare captured image shapes only. A similarity, a
Tesseract OCR string, or a font match is **not** validated evidence that the
images share a message, language, mechanism, or origin. Actual laser data
and independent, provenance-documented reference images are necessary for
a meaningful controlled experiment. Synthetic calibration results cannot
replace that evidence.

## Provenance and verification

Font hashes are pinned in
[`docs/codeofreality_font_manifest.json`](../codeofreality_font_manifest.json).
The maintainer supplied the files, reported direct creator permission over
Discord, and documented that claim in
[`docs/CODEOFREALITY_DISTRIBUTION_ATTESTATION.md`](../CODEOFREALITY_DISTRIBUTION_ATTESTATION.md).
That account has not been independently verified as a public license.
Preserve the provenance notice that ships with the binaries.

For each downloaded archive, compare its SHA-256 to the accompanying
`.zip.sha256` file. The ZIP's own `SHA256SUMS` lists the hash of every
packaged file.

This release is the first version intended to ship the CodeOfReality
comparison features on all four supported platforms. A passing automated
build does not substitute for independent end-user acceptance on every OS.
