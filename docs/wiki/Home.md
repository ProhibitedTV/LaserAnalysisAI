# Welcome to the LaserLab Wiki

**LaserLab** is an open-source, local-first desktop application for exploring patterns in recorded laser, diffraction, and speckle footage. It can compare image features with control recordings, preserve blind review, and generate reports others can audit.

You do **not** need to be a programmer or trained researcher to try the desktop dashboard. You do need to record controls carefully before interpreting scientific results.

## Our research standard

We welcome honest observations, skeptical questions, unexpected findings, reproducible tests, and useful null results. LaserLab can measure patterns and candidate image features. It **cannot** prove that patterns constitute language, contain messages, or have a particular metaphysical, conscious, or external origin.

No account, Discord connection, cloud upload, or Veilbreak integration is required. Keep laser handling safe and obtain consent before sharing someone else's data.

For the detailed protocol, see the [Researcher Workflow](https://github.com/ProhibitedTV/LaserAnalysisAI/blob/main/docs/researcher_workflow.md).
