# CodeOfReality distribution — maintainer attestation

**Recorded 2026-11-19.** The repository maintainer explicitly authorized
integrating the seven CodeOfReality font files supplied in the project
discussion into GitHub and the next LaserLab release. The maintainer states
that this authorization is based on direct permission from the font creator
over Discord. The original Discord exchange and its exact terms were **not**
provided here; this statement records the maintainer's attestation, not an
independently inspected copyright license or a quotation from the creator.

The attestation concerns these exact files, fingerprinted in
`docs/codeofreality_font_manifest.json`:

- `CodeOfRealityV1.otf`
- `CodeOfReality.ttf`
- `CodeOfReality-Circuit.ttf`
- `CodeOfReality-Oracle.ttf`
- `CodeOfRealitySymbols 2.ttf`
- `CodeOfRealitySymbols-3D.ttf`
- `CodeOfRealitySymbols-Outline.ttf`

**Attribution:** Classic files contain copyright metadata crediting Chris
Johnson (2026). Symbols files contain metadata identifying Luke Hearn as a
designer. These credits should be retained; they are not independently
verified to identify all parties holding redistribution rights.

**Intended research use:** Compare the reference glyph shapes from these
fonts with opt-in laser-light images and separately submitted examples of
symbols people report seeing during DMT experiences. Record Tesseract OCR
output as a distinct, fallible baseline, not as a confirmed translation.
Template matches are *visual hypotheses only* and do not demonstrate that
unusual visual patterns form a language or share an origin.

This document does not license the font files for unrelated projects. Keep
the original permission message in release records where feasible and honor
any additional rights-holder conditions or withdrawal request.
