# Security Policy

## Supported versions

For bug fixes and security review, prioritize the latest available released version and the current default branch. Older builds may not receive backports.

## Report security vulnerabilities privately

**Do not post exploit details, API keys, passwords, participant data, or sensitive local file paths in public Issues or Discussions.**

If available in this repository, use **Security > Advisories > Report a vulnerability** to contact maintainers privately. If private vulnerability reporting has not been configured, request a private reporting channel from the maintainer without publishing vulnerability details.

Do not test security issues against systems, accounts, or data you do not own or have permission to use. There is currently no guaranteed response timeline or formal bounty program.

For ordinary non-sensitive crashes and usability problems, use the [bug report form](https://github.com/ProhibitedTV/LaserAnalysisAI/issues/new/choose) with redacted diagnostic details.
